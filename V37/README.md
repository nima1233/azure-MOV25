### Storage account

Skapar storage account ```stnovatrix123``` med primary service Azure blob storage or Azure data lake storage då vi ska jobba med blob storage. Det viktigaste här var att använda locally reduandant storage (LRS) och performance standard för att hålla kostnaderna nere.

### Blob container

Skapar blob container med namnet ```arenden``` och anonymous access level ska vara private för att kunna ha mer kontroll över vem som har åtkomst.
